      cd tb
      for s in 0.00 0.25 0.50 0.75; do
        tag=sp$(printf '%02d' $(echo "$s*100/1" | bc))
        for cfg in nogate gated; do
          make clean
          SAIF_OUT=$NETD/activity_${cfg}_${tag}.saif \
          make SIM=questa TEST=pe_mixed_gl POWER=1 \
               GL_NETLIST=$NETD/pe_mixed_${cfg}_abcfix.v GL_LIB_V=$GL_VERILOG \
               TESTCASE=test_power_stimulus COCOTB_TESTCASE=test_power_stimulus \
               TB_SPARSITY=$s TB_POWER_CYCLES=4000 \
            | tee logs/gl_power_${cfg}_${tag}.log
          [ -s $NETD/activity_${cfg}_${tag}.saif ] || echo "!! EMPTY SAIF: $cfg $tag"
        done
      done
      cd ..
      Check: each log ran only test_power_stimulus; "measured zero-operand" ~ target.
      Optional: repeat with TB_POWER_MODE=int4x2 for an INT4x2 curve.

[ ] A3. Power per SAIF

1. Check the SAIF scope first

A wrong scope silently annotates nothing, so look before running:

head -30 $NETD/activity_gated_sp50.saif

Find the first (INSTANCE ...) line. For a run with work.pe_mixed as top, the name should be pe_mixed. If it is something else, such as tb/pe_mixed, use that as SAIF_SCOPE below.

2. One trial run (gated, 50%) before the loop

NETLIST=$NETD/pe_mixed_gated_abcfix.v SAIF=$NETD/activity_gated_sp50.saif \
SAIF_SCOPE=pe_mixed TOP=pe_mixed CLK_NS=4.0 \
  sta -exit -f sta_pe.tcl | tee logs/sta_gated_sp50.log

Check the log for three things:
- SAIF annotation: no read_saif failed warning. If you see one, fix the scope before continuing.
- Power report: no report_power unavailable.
- Internal power: the Internal column is not zero. If it is zero for everything, the Liberty file has no power tables, so OpenSTA can only give leakage and you should stay with the gl_power.py numbers. In that case, send me the log and I'll confirm.

3. All eight power runs

for cfg in nogate gated; do
  for s in 00 25 50 75; do
    NETLIST=$NETD/pe_mixed_${cfg}_abcfix.v SAIF=$NETD/activity_${cfg}_sp${s}.saif \
    SAIF_SCOPE=pe_mixed TOP=pe_mixed CLK_NS=4.0 \
      sta -exit -f sta_pe.tcl | tee logs/sta_${cfg}_sp${s}.log
    cp $NETD/power_pe_mixed_${cfg}_abcfix_saif.rpt $NETD/power_${cfg}_sp${s}_opensta.rpt
  done
done

The cp is needed because the script overwrites the power report each time. Check the real file name in reports/ after the first run. It is named after the netlist.

A sanity check for you

The gl_power.py result for the clk net was about 106 µW (no-gate). Compare it with the clock-net switching power in the OpenSTA report. They should be roughly the same order. If OpenSTA's is about 2.5× higher, it has scaled the activity to the 4 ns clock instead of the 10 ns simulation clock. That matters for the pJ/MAC row (energy per cycle uses the matching period), so tell me what you see.
