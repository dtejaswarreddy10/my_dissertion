1 · Broad Area of Work

VLSI design of hardware accelerators for deep-neural-network (DNN) inference — where digital microarchitecture, computer arithmetic and low-power design meet.

I design, verify and characterize a synthesizable systolic array — the matrix-multiply engine at the heart of Google TPU, NVIDIA Tensor Cores and AMD CDNA — in SystemVerilog RTL.

Architecture

Arithmetic

2 · Background — The Tension

Models keep growing; deployment targets (edge, automotive, mobile) keep shrinking their power budget.

3+ precision lanes

Precision heterogeneity — layers tolerate different quantization error; no fixed-precision array is optimal.

40–80% activations are zero

Structured sparsity — Ampere's 2:4 contract gives ~2× compute saving with tiny metadata.

60–70% power in the MAC datapath

Dynamic power dominates — operand isolation & clock gating must live in the RTL.

Background4

3 · Objectives — What I Will Achieve

O1

Baseline engine. Verified parameterized INT8 8×8 (→16×16) systolic array vs a Python GEMM golden model — zero mismatches.

O2

Precision-adaptive PE. Runtime switch between INT8 and packed INT4×2 (throughput doubling) via a shared reduction tree & accumulator.

O3

Sparsity front-end. Purely combinational 2:4 metadata decoder that suppresses zero-operand MACs without breaking systolic timing.

O4

Per-PE power gating. Operand isolation + integrated clock gating (ICG) that stops a PE's clock when both operands are zero — single clock domain, no CDC.

O5

Characterize & validate. FPGA (SAIF power) + open ASIC flow, normalized pJ/MAC, ResNet-18/MobileNetV2 validation, open-source release.

Inside each PE

  • Mode select → INT8 or INT4×2 on a shared partial-product reduction tree + INT32 accumulator
  • 2:4 decoder feeds only non-zero operand pairs
  • Zero detect → operand isolation + ICG kills switching & clock
  • DSP48-mapped MAC: one DSP per PE (MREG + PREG)

4 · Scope of Work

In Scope

  • Parameterized 8×8 / 16×16 output-stationary array
  • Two precision modes: INT8 & INT4×2 (shared tree + INT32 acc)
  • Combinational 2:4 sparsity decoder
  • Per-PE ICG + operand isolation (single clock domain)
  • SV + cocotb verification, >95% coverage
  • Vivado FPGA + Yosys/FreePDK45 ASIC, normalized pJ/MAC

Out of Scope

  • Full-chip tapeout (post-dissertation path)
  • DRAM controllers / weight loading / SoC integration
  • Training-time quantization (inference only)
  • Floating-point modes (FP8 / FP16 / BF16)
  • Unstructured sparsity
  • Multi-clock-domain / async interfaces
