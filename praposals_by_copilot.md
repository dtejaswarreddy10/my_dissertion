## 🎯 Top Dissertation Problem Statements (VLSI / RTL Focus)

### 🔹 1. Low-Power Configurable RISC-V Based AI Micro-Accelerator (RTL Level)
**Problem Statement:** Design and implement a lightweight, configurable RISC-V-based AI accelerator with custom instruction extensions for efficient matrix/vector operations at RTL level.

**Industry Importance:** AI accelerators are core to companies like NVIDIA, AMD, Qualcomm.

**Approach:**
- Use open-source RISC-V core (e.g., RV32IM)
- Add custom instructions for MAC operations
- Optimize datapath for area and power
- Implement in Verilog/SystemVerilog

**Expected Outcomes:**
- 20–40% performance improvement
- Reduced instruction cycles

**Publishability:** Focus on ISA extensions and microarchitecture optimization.
